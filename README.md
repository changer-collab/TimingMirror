# TimingMirror 择时镜子

> 当前仓库为**开发骨架 + 演示数据模式**：页面可运行、可交互，但计算引擎等核心能力尚未接入。
> 实施与决策的权威文档见 [`docs/implementation-baseline.md`](docs/implementation-baseline.md)（v1.1，approved 2026-10-10）。

## 项目用途与当前定位

面向个人投资者的交易行为分析工具：在浏览器本地读取你的交易记录，展示「实际收益 / 对照收益（买入不动口径）/ 择时损耗」的对比与证据，并支持行为规则候选的确认与共建。

- 运行形态：浏览器纯 JavaScript、零依赖；本仓库自带零依赖本地静态服务器用于开发预览。
- 确定性原则：金融数字由确定性计算产出（当前为合成夹具预期值），LLM 只做意图分类与事实复述。
- 合规口径：不荐股、不预测、不承诺收益、不替用户定规则；演示数字明确标注为演示数据。
- 隐私边界：原始 CSV 不上传；未来接入模型时仅发送按意图最小化的事实 JSON。

## 已实现的主要页面与功能

四个页面经 hash 路由（`#/import`、`#/report`、`#/chat`、`#/contract`），顶部为能力状态条（标注各模块"未接入"）：

| 页面 | 已实现 |
|---|---|
| 导入 · 确认（`#/import`） | 加载合成演示账单（5 条交易、占位代码 888888 / 000000）；交易列表展示费用/税费缺失标注与警告行；确认动作切换状态并跳转报告页；上传解析入口为未接入占位 |
| 报告 · 证据（`#/report`） | 场景切换（基准账单 A / A′ 仅改一笔卖出）与标的切换（组合 / 888888 / 000000）；四张指标卡（实际收益、对照收益、择时损耗 pp+元、股票本身涨幅显示"公式未定义"）；买入成本、期末持仓、现价、账单状态信息行；可展开的"证据与计算路径"（手算推导、数据来源与口径、开发说明）；A′ 差异面板（受影响指标前后值、保持不变项） |
| 对话（`#/chat`） | 离线降级占位回复、4 个预设问题芯片、输入发送与消息列表；回复带"离线模式（百炼未接入）"标签 |
| 契约（`#/contract`） | 2 条演示规则候选，支持确认 / 改写 / 拒绝并生成本地版本记录（localStorage 持久化）；历史情境模拟入口为禁用占位 |

数据统一经演示适配层 `src/demo/adapter.js` 读取 `m0/` 下的合成夹具（占位代码、合成价格；非真实证券、非真实行情）。

## 本地安装、启动与检查

要求：Node.js（开发与验证脚本使用 ES Modules；本项目零 npm 依赖，无需 `npm install`）。

```bash
npm run dev     # 本地静态服务器，默认 http://localhost:5180 （可用 --port= 覆盖）
npm run check   # m0 离线校验：csv-input 129 项 + market-cache 63 项 + calc-baseline 55 项
npm run smoke   # 前端交互冒烟（Node 最小 DOM 桩，非真实浏览器）：15 项
```

最近一次核验结果（2026-10-13）：`npm run check` 247 项全部通过；`npm run smoke` 15/15 通过。远程仓库**未配置 CI**（GitHub 显示 no checks reported），以上为本地命令结果。

## 当前开发状态与未接入能力

当前处于 M1 开发骨架阶段。以下能力**尚未接入**（页面内亦如实标注）：

- **计算引擎**：报告页数值来自合成夹具的预期值（`m0`），非由计算引擎实时计算产出；
- **真实 CSV 解析**：上传入口为占位；计划使用 Papa Parse 在浏览器本地解析（不上传）；
- **行情缓存**：真实行情已拉取为**草案**（`data/market-cache.json`，akshare 预拉 2023–2025，清单待负责人签收；签收前不构成支持范围声明、R2），产品页面仍读 `m0` 合成夹具；
- **百炼（LLM）**：对话为离线占位回复，未接入意图分类与事实 JSON 复述；
- **契约匹配 / 哈希存证 / 历史情境模拟**：契约页仅有演示级确认、改写、拒绝与版本记录；
- **独立复核、provenance、行为发现、报告图表（幽灵线双面板等）**：均未接入。

`m0/` 下的接口与 schema 候选均为草案状态（`frozen: false`），冻结评审按轮推进。

## 已知限制

- 演示数值为夹具预期值：切换标的/场景会读取对应夹具，但**输入改动不会触发重算**；
- `npm run smoke` 使用最小 DOM 桩验证视图逻辑，不替代真实浏览器核验；
- 报告页"股票本身涨幅"指标口径未定（显示"—"）；
- 契约"哈希存证"未接入（版本记录中标记为"未接入"）；
- 远程未配置 CI，回归依据为上述本地命令 + 人工/浏览器核验。

## 贡献与提交流程（简要）

1. 大功能单独开分支、单独提 PR，避免与其他模块混改；小范围修正也要保持改动可审计。
2. 提交前运行 `npm run check` 与 `npm run smoke`，并在 PR 描述中写明：改动内容、验证命令与结果、风险与回滚方式。
3. 报告纪律：区分「计划 / 已确认事实 / 实际改动 / 验证结果 / 未确认事项」；远程无 CI 时不得写成"CI 通过"。
4. Git 边界：按明确路径暂存（不使用 `git add .`）；提交/推送/合并按负责人当轮授权范围执行；禁止 reset --hard、force push 等破坏性操作。
5. 不提交凭证与真实账户数据；合成样例放 `m0/` 等夹具目录（提交边界见 [`.gitignore`](.gitignore) 与基线 §3 R5）。
