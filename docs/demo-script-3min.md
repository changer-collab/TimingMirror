## 演示前准备

- `npm run dev` → 打开 `http://localhost:5180`（全屏，建议 ≥1280 宽）。
- 首页默认落在「导入 · 确认」；报告页默认场景 A、标的"组合"。
- 全程口径（对应基线 §3 R1-R5 与 F-7）：演示账单＝合成夹具；**禁止**"真实跑出 / 真实用户收益"表述；统一称"演示数据·基于合成账单与合成行情计算"。
