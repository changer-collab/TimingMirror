## 0. 分工边界与工作方式

- 我负责：数据与确定性计算——拉数/行情缓存/CSV 格式与校验/计算引擎/单笔反事实/行为发现/契约匹配纯函数/区间证明，以及接口冻结的参会确认。
- 交付边界：UI 由吴涵晶实现（我提供引擎输出接口与夹具）；planner/百炼/复核骨架/部署由 changer；复核与 provenance 的编排（M1-C7/C8）由 changer，我提供带 formula_id 的 facts 结构。
- 硬口径（已确认，不重议）：费用/税费不入公式（Q1）；分红未计入（Q2）；金额估值用不复权价、前复权不参与相减（B2）；损耗＝对照−实际（F-2）；产品运行时纯浏览器 JS，Python 只做离线拉数与独立复算（A）。
- 工作方式（低 credits、可审计）：先只读后实施；每卡按「目标→依赖→交付物→验收命令→停止条件」执行；重复测试交本地终端 `npm run check / smoke`；完成后在 PR 描述记录验证命令与真实输出；状态不提前升级。
