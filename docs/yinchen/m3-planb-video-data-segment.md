## 1. 适用与边界

- 用途：M3 Plan B 视频中的「数据与可复算」段（约 70 秒），演示 R1 的核心承诺：改一笔卖出 → 受影响指标按预期变化、不受影响允许不变、每个数字可回源。
- 本段**不**演示 R2 真实签收范围：页面当前仍标注「合成夹具（草案·演示口径）」，真实缓存接入见任务 #33。口播不得声称「已接入真实行情」或「R2 已通过」。
- 若录制时页面已换真实缓存/标签，按页面实际标注改口播，并重跑 `docs/yinchen/m2c4-drill-prep.md` §2.2 后再录。

## 2. 录制前准备

1. 仓库根目录 `npm run dev`，浏览器打开 `http://localhost:5180`，窗口 ≥1280 宽，全屏。
2. 停在导入页（`#/import`），确认演示账单未加载（如已加载刷新页面）。
3. 屏幕录制区域含顶栏状态条（保留「合成夹具·演示口径」标注入镜，F-7）。
4. 准备 A′ 切换位置与证据展开位置，避免录制中找按钮。
