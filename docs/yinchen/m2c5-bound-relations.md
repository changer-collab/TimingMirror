## 1. 问题与形式化

基线 B 条要求：**仅在证明不同场景存在界关系后输出区间，否则并列展示、禁止拼接区间**。本报告对 S1–S4/V1–V2（B 组）中**当前可定义**的部分做界关系证明/证伪。

记号（单标的；组合为各标的求和）：

- 卖出笔 i：数量 `qᵢ`、成交价 `pᵢ`；估值日不复权收盘 `C`（B2）。
- 逐笔损耗 `dᵢ = qᵢ·(C − pᵢ)`（正＝相对损耗；负＝实际优于对照，F-2 双向归因）。
- 场景“替换 B（恢复为持有到估值日，不引入假设价格）”的**挽回额** `R(B) = Σᵢ∈B dᵢ`；**剩余损耗** `L(B) = D − R(B)`，其中 `D = Σ全部卖出 dᵢ = 组合 dragMoney`。
  - 推导引理（替换可加性）：实际值增量仅来自被替换卖出笔的 `dᵢ`，故 `L(B) = D − Σᵢ∈B dᵢ`。端点 `R(全部卖出) = D → L = 0`（等价于对照路径，恒等式②层级化）。

## 3. 可证界关系

**T1（精确，无条件）**：`R1(i) = dᵢ`。由恒等式①（Σ逐笔＝总损耗）逐笔项直接给出；与实现 `replaceSell.recoveredMoney` 数值一致（case-2：T003 → 200.00）。

**T2（条件单调性，可证）**：设批次 B 内全部 `dᵢ ≥ 0`，且 `i ∈ B₁ ⊆ B₂`：

`0 ≤ R1(i) = dᵢ ≤ R(B₁) ≤ R(B₂)`；剩余损耗反向 `D ≥ L(B₁) ≥ L(B₂) ≥ 0`。

推导：R 为对 dᵢ 的求和（引理），非负项集合的包含关系给出求和单调（两项相加非负）。
端点：`actual + R(全部卖出) = ghost`（case-2：2,325 + 275 = 2,600，测试断言）。
链式示例（case-2 全部 d ≥ 0）：`0 ≤ R1 = 200 ≤ R2b = 275 = R4`；多标的 demo-bill：`R2b(000000) = 3,000 ≤ R4 = 3,900`。

⇒ **条件式区间可证**：当纳入项全部 `d ≥ 0` 时，`[R1, R2b]`（或含 S2a 的细分组合）为有效界区间，且可附“全部逐笔损耗 ≥ 0”前置条件。

## 4. 证伪：无条件跨场景区间不可证

**T3（批内负损耗反例）**：`d₂ = +200`、`d₃ = −500` ⇒ `R2b = −300 < R1 = +200`，故“`R1 ≤ R2` 无条件成立”**被证伪**；剩余损耗序同样翻转（`L2b = 0 > L1 = −500`）。

**T4（跨标的反例）**：标的 A `d = +200`、标的 B `d = −500` ⇒ `R2b(A) = +200 > R4 = −300`，故“标的级 ≤ 组合级”**无条件不成立**。

负损耗为真实可出现情形（卖价高于估值日 close；F-2 双向归因；负数展示规则已由引擎覆盖）。⇒ **无条件 `[min, max]` 型区间不可证**（与基线风险 2 相符）；按基线 B 条，此时应并列展示。

## 6. 展示方案（供选型；不擅自决定）

- **方案甲（默认安全）**：多场景**并列**展示 + 逐项口径标签（S1/S2a/S2b/S4/V1 + 状态；S3/V2 标注“未定义”）+ 禁拼接。基线 B 条即此路。
- **方案乙（条件式区间）**：仅当全部纳入项 `d ≥ 0` 时输出 `[R1, R2b]` 并附前置条件徽标；条件不满足自动退回并列。
- 数据侧支撑（两方案通用）：每场景值可由 `drag_lines`（逐笔项）与 `replaceSell` 输出直接计算并带 `formula_id`/`display`；条件检查＝全项符号检查（确定性、可复核）。
- 若选乙：区间文案模板（涉及 T1-7 表述）需负责人确认；T1-7 的“非单点”表述在两方案下均满足（逐笔可加总＋可复算）。
